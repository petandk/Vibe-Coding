# Vibe-Coding 🚀🤖

Bienvenido a **Vibe-Coding**, un repositorio donde convergen la creatividad humana y el poder de la inteligencia artificial. Aquí encontrarás proyectos, ideas y experimentos desarrollados, en su mayoría, con la ayuda de una o varias IA. En muchos casos el código lo ha generado íntegramente una IA: yo pongo la idea, la dirección y las quejas; ellas, las líneas de código.

## 🧠 Filosofía del proyecto

Este repositorio nació para experimentar con el potencial de las IA en el desarrollo de software. Cada proyecto es una idea convertida en código con ayuda artificial, ya sea como copiloto, como ejecutora principal o como fuente de inspiración.

Lo que empezó como un experimento con una sola IA se ha convertido en un pequeño **banco de pruebas**: cada proyecto es también una forma de ver qué tal trabaja cada asistente, en qué destaca y dónde necesita un humano que le diga «eso no es lo que te he pedido».

## 🤝 Transparencia total

La idea es ser completamente transparente sobre quién hizo qué. Por eso cada proyecto indica qué IA lo escribió y qué parte puso el humano.

Esto se aplica también a este archivo. La primera versión de este `README.md` la redactó **Microsoft Copilot**. Esta actualización (octubre de 2026) la ha escrito **Claude**, de Anthropic: ha añadido la tabla de proyectos y la lista de colaboradores, sobre la información que le dio petandk.

## 📌 Nota importante

Este repositorio no pretende reemplazar el trabajo humano, sino mostrar cómo la inteligencia artificial puede ser una herramienta poderosa para potenciar la creatividad, acelerar el desarrollo y abrir nuevas posibilidades.

Son proyectos personales y experimentales: úsalos con cabeza, lee el README de cada uno y, si algo puede borrar archivos, prueba primero en una carpeta de prueba.
